# 小桶平台配置与验证流程

名称：vibe coding桌面迷你垃圾桶伙伴。角色昵称：小桶。角色定义正文共1288个字符，含六标签，不含本说明。

## 配置顺序

1. 在灵机一动Agent基本信息中填写上述名称与昵称，角色框粘贴role.txt；按实际界面保存草稿。
2. 把dialogue.md中的开场、结束、打断和安抚话术按界面字段填入。先使用短句，不把全部研究内容塞进开场白。
3. 核心知识优先使用knowledge.txt或七篇docs专题；先上传一篇，实际询问并检查能否检索到，再扩展。DOCX、XLSX、CSV及网页是否支持导入，以平台当前界面和实测为准。
4. 2400条样例按意图、条件挑选少量示例；120 FAQ用于需求澄清和续聊参考。它们是合成设计资料，不是模型已学会或测试通过证明。
5. 研究及代码参考单独存放，避免把别家产品能力当成小桶能力。8个代码项目均待用户确认，没有下载采用。
6. 绑定真实产品、设备控制插件和物模型字段。灯光、播报、录音、视觉、开盖与停止分别检查工具输入和回执；本文不虚构平台工具名称。
7. 电脑桥接再核对真实会话/轮次/审批标识，先验回复完成到口述续聊，再验具体审批到本次允许/拒绝。核心语音和设备控制继续走比赛指定平台与主板。
8. 最后按64条独立验收题填写真实回复和证据。先测普通成功，再测断链、重复、歧义、过期、多任务和完全勿扰；本包64题仍未运行。

## 自动续聊的启用条件

用户明确同意自动续聊；当前目标会话唯一；麦克风获允许且有采集指示；普通指令识别清楚；桥接已接通。满足时不需要每句话都再问一次。目标、否定词、授权范围不清或涉及删除、发布、付费时先核对。单轮自动录音不等于全天录音；连续对话必须另有明确模式与退出方式。

## 何时提醒

先处理停止与机构异常，再处理用户主动说话；普通编码事件依用户允许的方式提示。只亮灯不播报；完全勿扰不发普通声光。真实请求保留待处理，安静与未回应不会触发授权。坐姿提醒仅停稳且状态有效时进行，用户正在倾诉或讲话时延后。

## 当前进展的使用方式

2026年10月31日，用户在视觉聊天提供“平台与设备闭环跑通”的最新状态，本包记录为用户报告，并非本聊天新增实机验收。真实编码事件、语音回传和原生审批仍须逐项验证。实际运行时以当前工具和回执为准；机械孔口、轮组和打印候选不作为开盖已经可安全执行的证明。

## 在线入库

本包网页为公开静态站点加交互脚本，支持手机阅读、FAQ搜索筛选和角色复制；没有接入实时设备。若平台网页导入不运行JavaScript，可优先导入knowledge.md、knowledge.txt和faq.md静态正文。入库成功、切片质量和召回效果需在平台里实际测试。
